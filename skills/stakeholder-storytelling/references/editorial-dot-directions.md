# Optional editorial dot, halftone, and geometric directions

These are optional art directions distilled from references supplied for this workshop. They are not one fixed template. Ask for and inspect the user's own references first; use this guide when the user chooses this family of styles or asks you to propose it.

## Distinguish the visual materials

| Material | Observable visual character | Where it may help |
| --- | --- | --- |
| Halftone or crosshatched object | Tonal depth built from dots or fine woven lines, paired with sharp type and a restrained accent | A recognizable object can carry a well-matched metaphor while retaining an editorial print character |
| Dot-built diagram or map | Regular points form a meaningful silhouette, grouping, boundary, or path | Coverage, distributed work, relationships, or many units forming a whole |
| Dithered or pixel field | Small square marks shift in density, coalesce, separate, or build a contour | Aggregation, fragmentation, a threshold, or a transition between states, when that structure fits the idea |
| Technical geometry | Hairline grids, arcs, registration marks, aligned labels, and generous spacing | A system, constraint, dependency, or comparison that benefits from visible structure |
| Luminous point field | Sparse highlights and restrained light against a dark field | Focus, connectivity, or a signal becoming visible, if the setting supports a screen-oriented treatment |

Dot connectors, dot-built images, halftone texture, and background grids are different choices. Do not treat the word "dotted" as an instruction to use all of them.

## Shared composition principles

Use a clear typographic hierarchy and a small number of deliberate visual anchors. Give the main idea enough space. Keep texture subordinate to labels and evidence. A dark field, warm light ground, muted green, electric blue, or bright accent can all belong to this family; pick a coherent palette from the chosen reference rather than mixing every example.

Let different sections use different visual forms when their explanatory jobs differ. Keep typography, alignment, annotation, and color meanings coherent across them. A process diagram need not become halftone merely because the opening illustration uses that texture.

## Adapt references to stakeholder work

Poster-size type, oversized objects, texture, and extreme contrast need adjustment for explanatory content. Preserve the reference's hierarchy and character while providing the labels, definitions, comparisons, and source notes the stakeholder needs.

Build an original composition. Do not carry over reference logos, campaign wording, or implied endorsements. Use suitable original or authorized imagery if an object illustration is necessary. Describing a reference's style does not make the reference image part of the distributable library.

Textures can create interference patterns when scaled or projected. Test them at the real output size. Keep fine textures away from small text. A plain background is preferable when the texture weakens comprehension.

When marks represent quantities, define the mapping and keep it accurate. When they are illustrative, make that role clear and do not let their count or density imply unsupported data.

## Explain the proposed direction simply

For example: "I would use a light background, dark editorial type, and one dot-built diagram to show how the separate teams connect. The labels stay clean so it remains readable on a shared screen."

This illustrates how to explain a direction, not a default theme. Ask about a meaningful uncertainty instead of silently deciding what the user intended.
