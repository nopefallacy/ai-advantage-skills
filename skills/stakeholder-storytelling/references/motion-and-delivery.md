# Motion and delivery

Animation must explain something or help the viewer follow it. Match the movement to the intended reading order and the presenter's pace.

## Explain through change

Establish a readable state, reveal the meaningful change, and allow the viewer to inspect its consequence. Preserve the identity and spatial position of objects when that helps them track a transformation. When the argument changes, remove elements that no longer belong to it.

For a process, animate the actual sequence or dependency. For a comparison, keep anchors aligned. For a change in grouping, show where the same items move. Avoid arbitrary entrances that make the audience keep reconstructing the diagram.

Use deliberate easing and consistent timing suited to the viewing format. Hold labels long enough to read. Avoid competing movement around the point that needs attention. Decorative loops are optional and should be removed if they distract from reasoning.

## Respect the presentation format

An HTML scene can test motion and interaction, but it is not evidence that the same animation will work in presentation software. Choose supported transitions for the required format. If a visual requires a browser, explain that before making it essential to the story.

For live presenting, provide useful pacing or step controls rather than forcing the speaker to follow an automatic loop. For reduced-motion or static delivery, provide a complete, legible settled state. For editable decks, retain editable text and diagram components where feasible.

For dashboards, use motion for feedback and continuity. Do not animate measures in a way that makes intermediate values look like real observations. Make filter changes, loading, empty results, and errors understandable.

## Verify what the user will experience

Watch a continuous run at normal speed in the target viewer. Check text readability during and after movement, object continuity, transitions, and control behavior. Test replay and navigation if provided. Inspect the static or reduced-motion alternative as well.

Report the actual viewer and format tested. A screenshot review validates a frame's appearance; it does not validate motion, editable output, or compatibility with another presentation application.
